# Data attribution

The added DIC aliases and RUS form records are adapted from the OpenRussian
dictionary dataset, repository commit
[`50e210c4803237779cb562bc1abcea529066031c`](https://github.com/Badestrand/russian-dictionary/commit/50e210c4803237779cb562bc1abcea529066031c).
The dataset is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Those adapted OpenRussian overlay records are distributed under the same
license. The repository's LTGOLD base dictionaries are loaded separately by
the sentence engine and are not copied into these overlay files.

The source CSV URLs and SHA-256 checksums are listed in `source-manifest.json`.
OpenRussian credits sources including Wiktionary attributes and flexions,
Dicipedia translations, and Starling flexions. The dataset's own README warns
that the checked-in CSVs are older backup exports.
