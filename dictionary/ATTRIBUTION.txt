Language data for English → Russian Offline Translator

lex-*.tsv — WikDict by Karl Bartel and contributors, based on English
Wiktionary contributors’ material extracted by DBnary (Université Grenoble
Alpes, Getalp/LIG). From the dated WikDict SQLite 2_2026-11 English to Russian
export. The entries were filtered to single headwords and single target
lemmas, stress marks normalized, target parts of speech checked, and candidate
sets sorted/deduplicated. The adapted lexicon is CC BY-SA 4.0.

stripped of unneeded forms, and encoded as prefix deltas. This adaptation
is distributed as CC BY-SA 3.0.

To regenerate using the pinned inputs (no runtime installation needed):
  python -m pip install pymorphy3==2.0.6 pymorphy3-dicts-ru==2.4.417150.4580142
  python tools/export_dictionary.py en-ru.sqlite3 WordNet-3.0.tar.gz dictionary
